# Política de Seguridad

Este repositorio debe mantenerse privado por defecto.

## No subir nunca

- RUT completos
- datos de salud identificables
- fichas clínicas reales
- consentimientos firmados reales
- datos personales de trabajadores
- carpetas personales reales
- contratos con información sensible
- documentos internos no autorizados
- claves, tokens, contraseñas o archivos .env
- bases de datos sin anonimizar

## Regla de trabajo

1. Todo dato real debe anonimizarse.
2. Todo documento estratégico debe marcarse como interno.
3. Todo archivo público debe revisarse antes de publicarlo.
4. Las automatizaciones deben tener logs y manejo de errores.
5. Codex no debe recibir claves ni datos personales.
